About URL Encoding & Percent-Encoding

URL encoding (officially known as percent-encoding) replaces unsafe ASCII characters with a `%` followed by two hexadecimal digits. Because URLs can only be transmitted over the Internet using the restricted ASCII character set, characters like spaces, symbols, and non-ASCII international letters must be converted to avoid breaking HTTP request parameters.

When to Encode

Use encoding when passing user inputs, query parameters, or file paths through URL query strings (e.g., changing spaces to %20).

100% Client-Side Security

All encoding and decoding processes execute directly inside your browser via JavaScript. Your text and query strings are never sent to external servers.
